# Security Policy

Please use GitHub's **private vulnerability reporting** for [triump0870/AI-Job-Hunt](https://github.com/triump0870/AI-Job-Hunt/security/advisories/new), if that workflow is enabled. Include impact, safe reproduction steps, and affected versions; **never** include actual users' credentials, resumes or recruiter messages.

The repository owner, **Rohan Roy**, must enable private vulnerability reporting under GitHub repository settings before publication. If that link is unavailable, do not post an exploit in a public issue; wait until a verified private contact channel is announced.

Do not use public GitHub issues for unpatched exploit details. The maintainers will acknowledge receipt when possible, investigate, coordinate remediation and arrange an appropriate disclosure time.

No production-target scanning, credential theft, CAPTCHA bypass or access to third-party accounts is authorized by this policy. Security research remains subject to the [LICENSE](LICENSE) and applicable law.
